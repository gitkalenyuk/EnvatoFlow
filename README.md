**EnvatoFlow** — це потужний автономний багатопотоковий скрапер для масового завантаження відео з каталогу **Envato Elements** без водяних знаків та без активної платної підписки. 

Інструмент оснащено розумною системою фільтрації співвідношення сторін (**16:9** для YouTube/ПК або **9:16** для Reels/TikTok/Shorts), системою паралельного завантаження через TLS-емуляцію браузера, а також автоматичною генерацією **контактної сітки кадрів (Preview Sheet)** для миттєвого візуального аналізу змісту кожного ролика.

---

## 🌟 Ключові можливості

* 🚫 **Чисті відео без водяного знаку:** Витягує прямі посилання на файли прев'ю високої якості (`preview_540p_crf22_higher_quality.mp4`) з внутрішнього дерева гідратації сайту та завантажує їх безпосередньо з відкритого CDN Amazon S3/CloudFront.
* 🛡️ **Обхід захисту Cloudflare:** Побудовано на базі `curl_cffi` із повною емуляцією відбитків браузера Chrome (JA3/TLS Fingerprints), що гарантує стабільний доступ без блокувань 403 та без капч.
* 📐 **Фільтрація орієнтації (16:9 та 9:16):** Точний відбір як горизонтальних відео (16:9), так і вертикальних форматів (9:16) як на рівні пошукового URL, так і за точним математичним значенням `aspectRatio`.
* 🎞️ **Автоматична контактна сітка кадрів (Contact Sheet):**
  * Створює наочну JPG-розкадровку відео з точними мітками таймкодів на кожному кадрі.
  * **Адаптивний крок:** для відео 9с кадр береться щосекунди (0s, 1s, 2s...); для 18с — кожні 2 секунди, або з довільним фіксованим кроком (`--frame-step`).
* ⚡ **Багатопотокова черга завантаження:** Одночасний збір посилань і завантаження кількох MP4 файлів у паралельних потоках (`ThreadPoolExecutor`).
* 🔁 **Контроль дублікатів (Resume/Skip):** Автоматично визначає раніше завантажені файли та пропускає їх, заощаджуючи мережевий трафік.
* 📋 **Повний маніфест даних:** Зберігає структурований JSON-файл `metadata.json` з інформацією про автора, орієнтацію, тривалість, прямий лінк і шлях до файлу сітки.
* 👻 **Фоновий режим без зайвих вікон:** Включає готовий скрипт для непомітного запуску у фоні Windows з веденням журналу `scraper.log`.

## 🚀 Інструкція з використання

### 1. Завантаження вертикальних відео (9:16) для Reels / TikTok / Shorts
```bash
python scraper.py --url "https://elements.envato.com/stock-video/hello+kitty" --aspect-ratio 9:16 --limit 10 --threads 4
```

### 2. Завантаження горизонтальних відео (16:9) для стандартних відео
```bash
python scraper.py --url "https://elements.envato.com/stock-video/nature" --aspect-ratio 16:9 --limit 20 --threads 5
```

### 3. Пошук за довільним запитом
Можна передавати не лише повний URL, а й звичайні пошукові слова:
```bash
python scraper.py --url "cyberpunk city" --aspect-ratio 16:9 --pages 2 --limit 15
```

### 4. Власний крок розкадровки кадрів
Якщо вам потрібен кадр, наприклад, кожні 2 секунди замість автоматичного розрахунку:
```bash
python scraper.py --url "cars" --frame-step 2
```

### 5. Вимкнення створення сітки кадрів (тільки MP4)
```bash
python scraper.py --url "cats" --no-sheet
```

### 6. Запуск у прихованому фоновому режимі (Windows)
```powershell
.\run_background.ps1 -Url "https://elements.envato.com/stock-video/hello+kitty" -AspectRatio 9:16 -Pages 2 -Threads 5 -Output "./downloads"
```
* **Перегляд журналу роботи у фоні в реальному часі:**
  ```powershell
  Get-Content scraper.log -Wait -Tail 20
  ```

## ⚙️ Огляд параметрів командного рядка

| Параметр | Скорочення | За замовчуванням | Опис |
| :--- | :---: | :---: | :--- |
| `--url` | `-u` | `hello kitty` URL | Повний URL пошуку Envato або ключові слова |
| `--aspect-ratio` | `-ar` | `all` | Фільтр: `16:9` (горизонтальні), `9:16` (вертикальні) або `all` |
| `--pages` | `-p` | `1` | Кількість сторінок видачі для обробки (або `all`) |
| `--threads` | `-t` | `5` | Кількість паралельних потоків обробки |
| `--output` | `-o` | `./downloads` | Папка для збереження завантажених файлів |
| `--limit` | `-l` | `None` | Максимальна кількість відео для завантаження |
| `--frame-step` | — | `auto` | Крок у секундах для вибірки кадрів у сітку |
| `--no-sheet` | — | `False` | Вимкнути створення контактної сітки кадрів |
| `--log` | — | `scraper.log` | Шлях до файлу логів |
| `--skip-download`| — | `False` | Лише зібрати метадані у `metadata.json` без завантаження |
| `--verbose` | `-v` | `False` | Увімкнути детальні логи налагодження |

## 📁 Структура проєкту

```text
EnvatoFlow/
├── scraper.py             # Основний скрипт скрапера та генератора сіток
├── run_background.ps1     # Скрипт PowerShell для прихованого фонового запуску
├── requirements.txt       # Залежності проєкту (curl_cffi, opencv, Pillow, numpy)
├── .gitignore             # Виключення тимчасових та завантажених файлів
├── README.md              # Документація проєкту
└── downloads/             # Папка виводу (створюється автоматично)
    ├── *.mp4              # Завантажені відео без водяного знаку
    ├── metadata.json      # Детальний JSON-маніфест
    └── sheets/            # Контактні сітки розкадровок (*_sheet.jpg)
```
